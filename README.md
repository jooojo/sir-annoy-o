# AnnoyO

一个原生 macOS 菜单栏 Bilibili 纯音频播放器。

## 功能

- 在菜单栏常驻，主界面使用无封面、首尾相连的纵向滚筒播放列表
- 六首以内的滚筒只展示每项一次，并在头尾继续滚动时回绕；较长列表使用无感周期重心复位
- 顶部直接提供搜索框；提交搜索后播放列表持续滚动，结果就绪时切换为滚筒搜索页，返回时恢复列表离开前的位置，搜索支持触底分页加载
- 右上角齿轮打开设置弹层，集中展示账号、当前浏览列表删除、缓存与退出入口；漫游列表的删除操作禁用
- 当前播放项使用由真实 PCM 的四频带能量与频谱瞬态驱动的动态蚀刻波纹，暂停时停止；左右灰度分界展示播放进度，长按后横向拖动可预览并在松手时跳转播放
- 内置不可删除、不可重命名的“漫游”系统列表；播放后只保留上一首、当前和下一首的三槽窗口
- 漫游下一首默认取 Bilibili 对当前视频的相关推荐 Top 1；从搜索置入时会替换现有下一首，并优先于尚未返回的自动推荐
- 使用可持久化播放队列，普通列表支持加入、随机播放、下一首播放、动画删除和重启恢复
- 浏览、前后切换或新建列表不会中断当前音频；定位当前可切回播放来源列表
- 播放队列始终属于当前列表，增删和播放进度会直接持久化；随机播放不会改变列表顺序
- 用户主动新建的列表使用最小可用的“播放列表N”，删除或重命名释放的序号会被后续新列表复用；主页点击普通列表标题可重命名
- 边播放边缓存音轨，默认使用 2GB LRU 本地缓存，并在账号弹层展示占用与清理入口
- 支持手机 Bilibili 扫码登录，登录状态由系统 Cookie 容器保存
- 只请求 Bilibili DASH 音轨，不加载视频画面
- 当前播放项在悬停时显示播放/暂停与删除；音量跟随 macOS 系统音量
- 滚筒列表中的任意项目都可通过右键菜单打开原始 Bilibili 视频
- 顶部胶囊依次提供播放/暂停、定位当前和播放模式；播放模式默认列表循环，并在列表循环、单曲循环、列表随机间互斥切换
- 列表随机不会改变列表顺序，选择下一首时会排除当前正在播放的项目
- 自动识别多分P视频，并在同一视频内连续播放全部分P
- 支持 macOS 系统媒体键和“正在播放”信息
- 可随时跳转到当前视频的 Bilibili 页面

## 本地运行

要求 macOS 13 或更高版本，以及编译器与当前 macOS SDK 版本匹配的 Xcode 或 Command Line Tools。构建脚本默认使用 `xcrun --sdk macosx` 选择当前工具链，不会降级到旧 SDK。

```bash
swift run AnnoyO
```

启动后点击菜单栏的波形图标。

## 构建 `.app`

```bash
./scripts/build-app.sh
open dist/AnnoyO.app
```

构建结果使用 ad-hoc 签名，适合本机直接运行。正式分发需要 Apple Developer 签名与公证。

## 校验

```bash
./scripts/check.sh
ANNOYO_LIVE_TESTS=1 ./scripts/check.sh
```

第二条命令会实际搜索 Bilibili 并解析一条 DASH 音轨。

## 说明

AnnoyO 使用 Bilibili 的匿名网页接口和 WBI 签名。部分会员、付费、地区限制或登录后才可播放的内容可能无法播放。音轨仅用于播放与本地 LRU 缓存，不提供媒体文件导出。
